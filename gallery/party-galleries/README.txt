AUTOMATIC PARTY GALLERIES

1. Rename an empty folder to the party name you want shown on the website.
   Example: Sofia's Quince at The Cruz Building

2. Drop that party's photos and videos into the renamed folder.

3. Push the changes to GitHub. The website will automatically create a new
   clickable card and a complete gallery page for that party.

Helpful details:
- Empty folders stay hidden.
- The first photo alphabetically becomes the cover photo.
- Add 01, 02, 03, and so on to filenames to control their order.
- JPG, PNG, WebP, MP4, M4V, WebM, and MOV files are supported.
- MP4 is the safest video format for phones and browsers.
- Rename the folder and push again whenever you want to change the party title.
