What to know before booking

The XDJ-XZ is the catalog’s standalone controller option. The RMX-1000 is a separate remix and effects station. Individual CDJ 3000 players can be added in the main catalog when more than one unit is required.

What is included in the club package?

The package includes two Pioneer CDJ 3000 players and one Pioneer DJM-900NXS2 mixer.

Are these prices hourly?

No. The DJ equipment options on this page use the existing daily catalog rates.

Can I rent a CDJ by itself?

Yes. One CDJ 3000 is listed separately at the daily catalog price; use the main catalog if you need to select multiple units.

Is DJ service included?

No. This page covers equipment rental. Professional DJ coverage is a separate service in the Rentals & Builds catalog.
